# Billy OpenAPI contract

`billy.yaml` is an independently maintained OpenAPI 3.1 description used to generate this plugin's MCP tools. It was derived from Billy's public API documentation and common Billy resource conventions; `x-source` fields retain links to the relevant documentation pages.

The contract is not an official Billy artifact and may lag behind the live API. Read-only defaults, upstream authorization, pre-write reads, and post-write verification remain necessary even when the schema validates a request.
